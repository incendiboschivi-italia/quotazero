# QuotaZero 🏔️

Web App mobile-first per la pianificazione di itinerari in montagna, trekking multi-giorno, gestione bivacchi e calcolo dei tempi di percorrenza (Metodo CAI e Munter).

## Funzionalità
- Pianificazione itinerari giornalieri e multi-tappa
- Calcolo tempi con formule CAI e Munter
- Importazione ed esportazione tracce `.gpx`
- Profilo altimetrico interattivo e checklist equipaggiamento dinamica
- Predisposizione salvataggio cloud tramite Supabase
